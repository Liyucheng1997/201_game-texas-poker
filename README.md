# 🎴 棋牌大厅 · 德州扑克 / 斗地主 / 斗牛 / 掼蛋

纯前端单机棋牌合集 —— 无任何依赖，下载后双击 `index.html` 即可游玩。

当前版本：**v2.1.0** · [在线游玩](https://liyucheng1997.github.io/201_game-texas-poker/)

## v2.0.0 更新

- 🎴 **棋牌大厅**：新增 **斗地主**、**斗牛（抢庄牛牛）**、**掼蛋** 三款游戏，与原来的德州扑克共用一个大厅。
- 🎚️ **四档难度**：简单 / 普通 / 困难 / 大师，每个游戏的 AI 在不同难度下使用不同的算法（见下表），不是简单地调参数。
- 🗺️ **闯关模式**：4 章 16 关，四种玩法交替出现、难度逐级提升，部分关卡带特殊规则（固定当地主、固定坐庄、短码生存……），每关按完成度评 1~3 星，进度保存在浏览器本地。
- ♠️ **德州扑克 AI 重做建模**：困难以上的对手不再把别人的底牌当随机牌，而是按每个人的加注、跟注、连续下注推断其手牌范围（范围加权蒙特卡洛）；大师对手还会统计你的入池率 / 加注率 / 被下注弃牌率，针对你的习惯调整诈唬和抓诈频率。胜率辅助新增底池赔率提示。
- ⏩ 快速模式（加快 AI 节奏）、统一的音效 / 静音、规则说明、结算与评星。

## v2.1.0 更新：声音

- 🗣️ **真人克隆配音**：每个角色有自己的声音（热血青年、老练男声、嚣张男声、低沉男声、活泼女声、慈祥奶奶，外加一位解说员），用本地 F5-TTS 克隆真人音色后，再做“激情化”后期（提速、升调、放大语调起伏、压缩、混响），不是机器朗读腔。
  - 斗地主 / 掼蛋：报牌（“对三！”“三个K！”“飞机！”“王炸！！”“大你！”“要不起”）、叫分、报单报双、进贡还贡、接风、头游、春天。
  - 斗牛：抢庄、押注、亮牌报牛（“牛牛！！”“五花牛！！”），庄家通杀 / 通赔由解说员播报。
  - 德州：过牌 / 跟注 / 加注 / “全下！梭哈！”，翻牌转牌河牌由解说员播报，摊牌时赢家喊出牌型。
  - 所有 AI 角色的台词气泡也会用各自的声音念出来。
- 🔊 **重做音效**：洗牌、拍牌、陶瓷筹码、金币、炸弹（引信 + 爆炸）、王炸（火箭 + 爆炸 + 鞭炮）、飞机呼啸、全下滚奏、春天唢呐 + 锣 + 鞭炮、胜利号角……全部由代码合成，无版权素材。
- 🎵 **背景音乐**：民乐喜庆（斗地主 / 斗牛 / 掼蛋）、赌场爵士（德州），有人快出完牌或全下时自动切到紧张配乐。
- 顶栏可分别开关 **配音 / 音乐 / 全部声音**。

## 🎚️ 难度设计

| 难度 | 德州扑克 | 斗地主 / 掼蛋 | 斗牛 |
|------|----------|---------------|------|
| 🌱 简单 | 胜率估计噪声大，偶尔随手乱打，爱跟注 | 能压就压、常乱拆牌，不分敌友 | 抢庄押注基本随机 |
| ⚔️ 普通 | 蒙特卡洛胜率 + 性格参数 | 手牌拆分（最少手数），不压队友 | 按牌力阈值决策 |
| 🔥 困难 | + 位置意识 + 按行动推断对手范围 | + 记牌、团队配合、看剩余张数 | 枚举第 5 张的精确期望收益 + 风险控制 |
| 👑 大师 | + 统计你的打法并针对性剥削 | + 按“不要”约束抽样推断未知牌，模拟到终局选最优出法 | + 对你的抢庄 / 押注习惯做贝叶斯建模 |

难度差异经过无头自对弈验证（`--sim` 可复现），例如：

- 斗地主：大师地主对简单农民胜率 94.8%，简单地主对大师农民仅 4.3%；大师地主对困难农民 67.3%（同难度基准 48.9%）。
- 掼蛋：困难队对普通队头游率 67%，大师队对困难队约 62%。
- 斗牛：平均每局盈亏 大师 +26.9 / 困难 +16.2 / 普通 −6.9 / 简单 −40.8。
- 德州：大师对普通每人每手 +25.9 筹码，普通对简单 +12.4。

## 🚀 运行

无需安装任何东西：直接用浏览器打开 `index.html`。或起个本地静态服务器：

```bash
python -m http.server 8321
```

然后访问 http://localhost:8321 。

## 🧪 测试

游戏逻辑与 DOM 解耦，可在 Node 中直接运行测试（含各难度 AI 的无头自对弈）：

```bash
node tests/texas.test.js
```

其余游戏同理：`tests/doudizhu.test.js`、`tests/douniu.test.js`、`tests/guandan.test.js`。德州、斗地主、斗牛的测试加 `--sim` 参数会跑更长的难度对比自对弈。

## 🎙️ 重新生成声音

声音文件已经生成在 `audio/` 下，直接游玩不需要任何工具。若要修改台词或换音色：

```bash
node tools/voice/collect.js > tools/voice/jobs.json
```

然后用装有 F5-TTS 的 Python 运行 `tools/voice/gen_voices.py`（只会补生成新增 / 改动过的台词，并带语音识别质检）。音效和配乐由 `tools/audio/make_audio.py` 生成。
