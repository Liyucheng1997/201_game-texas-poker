# ♠♥ 德州扑克 · Texas Hold'em ♦♣

纯前端单机德州扑克锦标赛 —— 无任何依赖，下载后双击 `index.html` 即可游玩。

当前版本：**v1.1.0** · [在线游玩](https://liyucheng1997.github.io/201_game-texas-poker/)

## v1.1.0 更新

- 放大公共牌、玩家手牌、文字和操作按钮。
- 保留已有牌面节点，修复过牌时重复播放发牌动画导致的闪烁。
- 在玩家区域直接显示大号回合提示，以及过牌、跟注、弃牌、加注和全下状态。
- 为真人和 AI 统一标记当前行动回合，并保留短暂停顿以便看清行动结果。

## 🎮 玩法

6 人淘汰锦标赛：你和 5 位 AI 每人 2000 筹码，盲注每 8 手上涨，输光筹码即出局，活到最后就是冠军。

### 五位性格迥异的对手

| 对手 | 风格 |
|------|------|
| 🦊 老狐狸 | 紧凶老手，出手必有好牌？也可能在下套 |
| 🐺 疯狗阿豪 | 什么牌都敢玩，诈唬成瘾，小心他梭哈 |
| 🗿 石头哥 | 极度保守，他加注了就快跑 |
| 🤓 教授 | 全靠数学，赔率不对绝不跟注 |
| 🐱 甜甜 | 好奇宝宝，什么牌都想跟着看看 |

AI 并非固定脚本：每次决策都通过蒙特卡洛模拟计算真实胜率，再叠加各自的性格参数（松紧度 / 激进度 / 诈唬率），因此打法真实、可以被读牌。

## ✨ 功能

- 完整德州扑克规则：盲注、加注、全下、**多人全下边池**正确分配
- 📊 新手辅助：可开启实时胜率显示 + 当前成牌提示
- 💬 AI 台词气泡，各有各的嘴炮
- 💥 全下对决自动亮牌、逐张发牌的戏剧效果
- 🏆 摊牌时金色高亮获胜的 5 张牌
- 加注滑条 + 半池 / 满池快捷按钮
- 键盘快捷键：`F` 弃牌 · `C` 过牌/跟注 · `R` 加注
- 音效（WebAudio 合成，可静音）、牌局记录、内置玩法说明

## 🚀 运行

无需安装任何东西：

```
直接用浏览器打开 index.html
```

或起个本地静态服务器：

```bash
python -m http.server 8321
# 访问 http://localhost:8321
```

## 📁 项目结构

```
index.html   页面结构
style.css    样式
game.js      全部游戏逻辑（发牌、牌力评估、边池、AI 决策、UI 渲染）
```

`game.js` 的核心逻辑（牌型评估 / 边池分配 / 蒙特卡洛胜率）与 DOM 解耦，可在 Node 中直接 `require` 进行单元测试。
